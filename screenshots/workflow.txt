SETUP INIZIALE
==============

    ┌─────────────────────────┐
    │  1. Installa Ollama     │
    │  https://ollama.ai      │
    └────────────┬────────────┘
                 │
                 ▼
    ┌─────────────────────────┐
    │  2. Avvia Ollama        │
    │  $ ollama serve         │
    └────────────┬────────────┘
                 │
                 ▼
    ┌─────────────────────────┐
    │  3. Scarica Granite4    │
    │  $ ollama pull granite4 │
    └────────────┬────────────┘
                 │
                 ▼
    ┌─────────────────────────┐
    │  4. Setup Python        │
    │  $ pip install -r       │
    │    requirements.txt     │
    └────────────┬────────────┘
                 │
                 ▼
    ┌─────────────────────────┐
    │  5. Verifica Setup      │
    │  $ python setup_check.py│
    └─────────────────────────┘

BEST PRACTICES
==============

1. Test della connessione
   └─→ Sempre eseguire setup_check.py prima

2. Primi passi
   └─→ Inizia con quick_test.py o ollama_basic.py

3. Sviluppo
   └─→ Usa ollama_advanced.py per app con stato

4. Debugging
   └─→ ollama_http.py per controllo completo

5. Uso quotidiano
   └─→ chatbot.py per interazione rapida

6. Coding assistant
   └─→ programming_tools.py per aiuto nello sviluppo
