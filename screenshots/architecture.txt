API Endpoints Disponibili
==========================

┌─────────────────────────────────────────────────────────┐
│ GET  /api/tags          → Lista modelli disponibili     │
├─────────────────────────────────────────────────────────┤
│ POST /api/generate      → Genera testo (prompt singolo) │
├─────────────────────────────────────────────────────────┤
│ POST /api/chat          → Chat con cronologia           │
├─────────────────────────────────────────────────────────┤
│ POST /api/embeddings    → Genera embeddings vettoriali  │
├─────────────────────────────────────────────────────────┤
│ POST /api/pull          → Scarica un modello            │
├─────────────────────────────────────────────────────────┤
│ POST /api/push          → Carica un modello custom      │
└─────────────────────────────────────────────────────────┘


Flusso di una Richiesta Chat
=============================

    1. Script Python
       │
       │ client.chat("Ciao!")
       │
    2. Libreria ollama
       │
       │ Costruisce JSON request
       │ {
       │   "model": "granite4",
       │   "messages": [...]
       │ }
       │
    3. HTTP POST → localhost:11434/api/chat
       │
    4. Ollama Server
       │
       │ • Carica modello in RAM
       │ • Esegue inferenza
       │ • Genera risposta
       │
    5. HTTP Response JSON
       │
       │ {
       │   "message": {
       │     "role": "assistant",
       │     "content": "Ciao! Come posso aiutarti?"
       │   }
       │ }
       │
    6. Libreria ollama
       │
       │ Parse della risposta
       │
    7. ← Script riceve risposta
       │
       print(risposta)


Gestione della Conversazione
=============================

Senza cronologia:
┌─────────┐
│ User: A │ → [Risposta 1]
└─────────┘

┌─────────┐
│ User: B │ → [Risposta 2] (non sa di A)
└─────────┘


Con cronologia (OllamaClient):
┌─────────┐
│ User: A │ → [Risposta 1]
└────┬────┘
     │ Salvata in history[]
     │
┌────▼────┐
│ User: B │ → [Risposta 2] (conosce contesto di A)
└────┬────┘
     │ Salvata in history[]
     │
┌────▼────┐
│ User: C │ → [Risposta 3] (conosce A e B)
└─────────┘
