PERCORSO CONSIGLIATO
====================

Per chi inizia:
    1. quick_test.py      → Verifica che funzioni
    2. setup_check.py     → Setup completo
    3. ollama_basic.py    → Impara le basi
    4. chatbot.py         → Prova l'interazione
    5. ollama_advanced.py → Sviluppa la tua app

Per sviluppatori:
    1. setup_check.py        → Verifica ambiente
    2. ollama_http.py        → Comprendi l'API
    3. ollama_advanced.py    → Base per il progetto
    4. programming_tools.py  → Assistente sviluppo
